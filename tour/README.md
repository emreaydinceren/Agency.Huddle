# Take the tour

See Agency.Huddle before you install it. Paste this into Claude Code or Claude Cowork, and Claude
walks you through Huddle with real screens, at your pace, and answers your questions from the
User Guide:

```text
Give me a tour of Agency.Huddle. Fetch only the tour/ folder of
https://github.com/emreaydinceren/Agency.Huddle (a shallow, sparse git clone; if git isn't
available, download the repository ZIP) and follow tour/TOUR.md.
```

It takes about ten minutes. You choose the way in: a Second Brain for your life and notes, agent
teams that build software, or both. Nothing is installed: Claude downloads this folder and the
documentation it answers from, and that's all.
