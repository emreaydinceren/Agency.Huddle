# Household basics

## When it applies

- Everyday household and school work that one family can take from start to Done without a written spec.
- The Task states its acceptance in one line, so the household manager can check it without a meeting.

## Stages

1. **Ready**: the Task has a title, an acceptance line and an owner. Done when the household manager assigns it.
2. **In progress**: the School Liaison gathers the facts from the school emails and drafts the to-dos, events or reply. Done when the draft is in the Task.
3. **Verify**: the household manager compares the draft with the source emails and posts an Evidence line. Done when that line exists.
4. **Done**: the Human marks the Task Done after reading the Evidence line.

## Who does what

- `household-manager` picks the Task, writes its acceptance line, checks the draft against the source emails and posts the Evidence line.
- `school-liaison` reads the school emails, turns them into to-dos, events and the weekly digest, and drafts replies for a parent to send.

## If a role is not hired

- No `school-liaison`: the household manager reads the school emails itself and writes the to-dos and the digest.
- The manager always verifies, so a Task that has no draft goes to the Human with the source emails quoted.

## Gates

- This process declares no hard gate. The household manager's Evidence line is the check before a Task is ready, and the Human closes each Task.

## Definition of Done

- Plan checked: evidence from verify
- Plan reviewed: document reviewed by verify

## Cadence

- Work the open Tasks in the order the household manager sets, and keep the number in progress small.
- A retro runs every 14 days.

## Escalation

- A school commitment, money, or a change to a standing arrangement goes to the Human.
- A disagreement between the household manager and the School Liaison goes to the Human with both views written on the Task.

## Onboarding

- Note which school mailboxes and calendars the family uses.
- Write Team Memory notes on the school's usual senders, the parents' preferences and the digest day.
- Propose a starter Task to the household manager.
